# Map Asset Notices

- `world.json` and `world_detailed.json`: derived from Natural Earth via `world-atlas@2`, public domain. Antarctica is removed for BI chart framing; Russia/Fiji dateline rings are unwrapped for ECharts rendering.
- `ne_50m_admin_0_boundary_lines_maritime_indicator.geojson`: Natural Earth Admin 0 maritime indicators, public domain. It is a cartographic reference overlay, not legal or navigational boundary data.
- `israel_districts.json`: derived from geoBoundaries ISR ADM1 (`gbOpen`), CC BY 4.0. Source: https://www.geoboundaries.org/api/current/gbOpen/ISR/ADM1/. District names are normalized to the application canonical names for deterministic matching.
